# FRAS V2 Context

This project is the revised version of FRAS after thesis panel recommendations.

Primary Goal:
Transform FRAS from an attendance recording system into a classroom presence monitoring system.

Primary User:
Professor

Core Workflow:
Today's Classes
→ Live Session
→ Session Review
→ Student Evidence
→ Finalize Attendance
→ Blackboard Sync

Important:
- Focus on professor workflows.
- Do not introduce unnecessary admin functionality.
- Attendance must be evidence-based.
- Attendance decisions must be traceable to attendance events.
- Preserve compatibility with the existing FRAS codebase where possible.
