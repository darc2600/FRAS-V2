# FRAS V2

## Purpose

FRAS V2 is a Classroom Presence Monitoring System.

Unlike V1 which focused on attendance recording,
V2 focuses on:

- Presence Monitoring
- Time In Tracking
- Break Tracking
- Time Out Tracking
- Session Validation
- Attendance Evidence

## Primary User

Professor

## Main Workflow

Today's Classes
→ Live Session
→ Session Review
→ Student Evidence
→ Finalize Attendance
→ Blackboard Sync

## Key Difference From V1

V1:
Attendance Result

V2:
Attendance Evidence + Validation
