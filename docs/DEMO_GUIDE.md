# FRAS Demo Guide

Use this as the suggested flow for thesis or stakeholder presentation.

## 1. Opening Summary

Introduce FRAS as a full-stack facial recognition attendance platform for academic attendance monitoring, student registration, reports, room schedules, analytics, and admin management.

## 2. Login and Dashboard

Show the redesigned login screen, then proceed to the dashboard/admin area.

Key talking points:

- Role-based system access
- Centralized attendance management
- Admin-ready interface

## 3. User Management

Show the user list and account management section.

Key talking points:

- Admin can manage accounts
- User types and statuses are visible
- Password reset workflow exists

## 4. Student Registration and Face Data

Show student registration and face-data related workflow.

Key talking points:

- Student profile information
- Face image dataset storage
- Recognition-readiness tracking

## 5. Room and Schedule Management

Show the room schedule section.

Key talking points:

- Class schedule visibility
- Room context for attendance
- Schedule editing support

## 6. Attendance Monitoring

Show attendance monitor and attendance logs.

Key talking points:

- Attendance captured into the database
- Logs can be reviewed later
- Admin can inspect attendance history

## 7. Attendance Reports

Show report filters and exports.

Key talking points:

- Class/professor report workflows
- Summary cards
- Export support

## 8. Analytics

Show the analytics page.

Key talking points:

- Student and instructor totals
- Attendance totals
- Face registration readiness
- Planned visual chart improvements

## 9. Support Tickets

Show support ticket submission and admin review.

Key talking points:

- Built-in issue reporting
- Admin-side support visibility

## 10. Closing

End by emphasizing that FRAS connects authentication, scheduling, student records, face recognition, attendance logs, reports, analytics, and support workflows into one integrated system.
