# Start Here - FRAS V2

This repository contains the original FRAS V1 work and the final FRAS V2 implementation. For thesis review, screenshots, appendices, and current development, start with FRAS V2.

## What FRAS V2 Is

FRAS V2 is a professor-centered classroom presence monitoring system using facial recognition embeddings. It focuses on the full class-session lifecycle:

```text
Login
-> Today's Classes
-> Class Roster
-> Face Profile Registration/Update
-> Live Session Monitoring
-> Manual Attendance / Facial Recognition Capture
-> Specific Student Break / Session Break
-> Return Detection Mode
-> Post-Session Review
-> Student Evidence
-> Professor Override / Mark Excused
-> Attendance Finalization
-> Session History
-> Blackboard-ready CSV Export
```

## Quick V2 Docker Check

From the repository root:

```bash
docker compose -f docker-compose.v2.yml ps
```

FastAPI docs, when the backend is running:

```text
http://localhost:8000/docs
```

Frontend, when the frontend container is running:

```text
http://localhost:8080
```

## Safe Test Command

The recognition decision unit test is safe to run because it does not reset or seed the database:

```powershell
.\.venv\Scripts\python.exe -m pytest tests\test_v2_recognition_decision.py -q
```

## Important Safety Notes

- Do not run database reset, seed, clear, or `--force` scripts unless you intentionally want to modify V2 data.
- Do not commit `.env` files, passwords, JWT secrets, SSH credentials, database dumps, private keys, or deployment archives.
- Blackboard-ready CSV export is generated by the frontend after finalization. It is not direct Blackboard API synchronization.
- V1 and admin-heavy code may remain in the repository, but it is background material for the final V2 thesis scope.
